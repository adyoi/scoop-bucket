# scoop-bucket

Scoop bucket for [tesseract-crypt](https://github.com/adyoi/tesseract-crypt) —
hybrid public-key string & file encryption.

```powershell
scoop bucket add adyoi https://github.com/adyoi/scoop-bucket
scoop install tesseract-crypt
```

The manifest is refreshed automatically on every release by the
`packages.yml` workflow in the main repository.
